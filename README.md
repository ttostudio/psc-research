# PSC: Provable Secure Computing

仕様と前提を明示し、どのバグを防げるかを、小さな実験から検証する研究です。Elmは検討する技術の一つで、最初から採用を前提にはしていません。

| 研究番号 | 問い | 検証結果 |
| --- | --- | --- |
| [PSC-001](PSC-001/) | 現在のバージョンがレビューされるまで確定を防げるか | 有限モデルの状態と操作の組み合わせ108件が仕様と一致 |
| [PSC-002](PSC-002/) | 同じ下書きへの別々の変更が、気づかないうちに上書きされるのを防げるか | 24条件で古いバージョンを基にした後着の保存を競合として検出 |

各実験に検証コード、実行手順、結果と限界を掲載しています。現時点の結果は **L2（テスト）** です。形式証明、実アプリでの安全性、Elmでの検証を示すものではありません。

GitHub Actionsの「研究結果の再現」でも、保存した検証結果と再実行結果を照合します。
