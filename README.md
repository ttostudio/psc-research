# PSC: Provable Secure Computing

最終目標は、仕様への違反や意図しない状態遷移を防ぎやすい独自のプログラミング言語を設計し、試作することです。現在は、その言語で何を保証すべきかを、小さな実験から調べています。独自言語はまだ実装していません。

1. **要件**：防ぎたいバグと保証する性質を、前提・反例とともに定める。
2. **意味論**：状態、操作、操作が許される条件を定義し、モデルと照合する。
3. **小さな実装**：言語の最小部分を試作し、同じケースで仕様と照合する。既存言語や検証手法は設計比較の参考にする。

| 研究番号 | 問い | 検証結果 |
| --- | --- | --- |
| [PSC-001](PSC-001/) | 現在のバージョンがレビューされるまで確定を防げるか | 有限モデルの状態と操作の組み合わせ108件が仕様と一致 |
| [PSC-002](PSC-002/) | 同じ下書きへの別々の変更が、気づかないうちに上書きされるのを防げるか | 24条件で古いバージョンを基にした後着の保存を競合として検出 |

各実験に検証コード、実行手順、結果と限界を掲載しています。現時点の結果は **L2（テスト）** です。形式証明、実アプリでの安全性、独自言語での動作を示すものではありません。

GitHub Actionsの「研究結果の再現」でも、保存した検証結果と再実行結果を照合します。
